********************9. XSS — Cross-Site Scripting***********************************************

XSS occurs when an attacker manages to make malicious JavaScript execute in another user's browser.

Example

Suppose a website displays:

Welcome <username>

without safely handling the input.

An attacker submits malicious HTML/JavaScript.

The browser may interpret it as code.

Types of XSS

There are three major types:

1. Stored XSS

Malicious input is stored on the server/database.

Attacker
   ↓
Comment
   ↓
Database
   ↓
Victim opens page
   ↓
Script executes
2. Reflected XSS

The malicious input is immediately reflected in the response.

Attacker → malicious URL → Server → Victim
3. DOM-based XSS

The vulnerability exists in client-side JavaScript/DOM manipulation.

Prevention
Output encoding
Proper HTML sanitization where appropriate
Avoid unsafe DOM APIs
Use Content Security Policy
Validate input where appropriate
