📌 Permissions (r, w, x)
r → read (4)
w → write (2)
x → execute (1)

Examples:

rw- = 6
r-x = 5
📌 Changing permissions
Command: chmod
Examples:
chmod 754 f1.py

📌 umask meaning
umask = User file creation mode mask
It controls default permissions of new files/folders
It removes permissions from base values:
Files start at 666
Directories start at 777

Example:

umask 022
files → 644
directories → 755
📌 Changing umask

Temporary:

umask 022

Check:

umask
Permanent:
Edit ~/.bashrc
Add umask 022

Apply:

source ~/.bashrc

.bashrc = Bash Run Commands file

Used for:
aliases

umask settings
customizing terminal
📌 Editing files
nano is a text editor
nano ~/.bashrc → edit bash configuration file
Important:

so you cannot run .bashrc directly

How many inode numbers are provided in a partition?

The number of inodes is determined when the filesystem is created. In ext4, Linux allocates a fixed inode table based on the partition
 size (typically about 1 inode per 16 KB). You can check the total inode count using df -i or tune2fs -l. In your /dev/sda2 partition, the
 total inode count is 1,310,720.
_____________________________________________________________________________________________________________________________________
What is an inode?

An inode is a data structure in Linux that stores metadata about a file such as permissions, owner, size, timestamps, and disk block 
locations. Each file is identified by an inode number. The filename itself is not stored in the inode.

Why do hard links have the same inode?
Because both filenames point to the same inode and therefore the same underlying file data.
_____________________________________________________________________________________________________________________________
What happens when a file is deleted?
Linux removes the filename-to-inode mapping. The inode and data remain until the link count becomes zero and no process is using the file.

PROCESS MANAGEMENT:

Process Management is the operating system's mechanism for managing running programs (processes). It involves creating, scheduling, 
monitoring, controlling, and terminating processes while efficiently allocating CPU, memory, and other system resources.

| State      | Meaning                                     |
| ---------- | ------------------------------------------- |
| New        | Process created                             |

| Waiting    | Waiting for I/O                             |
| Stopped    | Paused                                      |
| Zombie     | Finished but parent hasn't collected status |
| Terminated | Completely ended                            |

7. What is the kill command?

Interview Answer:
	The kill command is used to terminate a running process using its Process ID (PID). By default, it sends the SIGTERM (signal 15),
allowing the process to exit gracefully.

What is killall?

Interview Answer:
	The killall command terminates all processes that match a given process name. Unlike kill, which requires a PID, killall works directly 
with the process name.
