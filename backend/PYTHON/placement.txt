NETWORK INTRUSION DETECTION SYSTEM:

	1.My project is a **Network Intrusion Detection System**, developed using Python, Flask, React, and MongoDB.

	2.The main objective of the project is to **monitor network traffic and identify suspicious activities** such as port scanning, SYN flood attacks, and ARP spoofing.

	3.For the backend, I used **Python and Flask**, and I used **Scapy to capture and analyze network packets**. React is used to build the frontend dashboard, and MongoDB is used to 
store packets and security alerts.

	4.The basic workflow is that the system captures network packets, analyzes their protocols and behavior, and checks for suspicious patterns. For example, if a device scans more 
than a certain number of unique ports within a short time, the system generates a high-severity port-scan alert. Similarly, it can detect abnormal SYN traffic and ARP spoofing patterns.

	5.I also developed APIs for packets, alerts, statistics, and exporting the data. I added a dashboard to display the network activity and alerts.

	6.My main contribution was working on the **packet detection logic, attack detection, backend APIs, database integration, and connecting the backend with the React dashboard**.

	7.One challenge was handling and analyzing continuously captured network packets efficiently. I addressed this by processing packets based on specific protocols and detection rules
 rather than treating every packet the same.

Overall, this project helped me understand **network security, Python, APIs, databases, and how a security monitoring system works in a practical environment**.

___________________________________________________________________________________________________________________________________________________________________________________________

"I built a Network Intrusion Detection System — a security tool that watches your network traffic and alerts you when something suspicious happens.

The system does three things. It captures every packet in real time using Python and Scapy. It classifies them by protocol — HTTP, HTTPS, DNS, ARP, TCP, UDP. And it detects three types of attacks.

For port scan detection — if one IP hits more than 15 unique ports in 5 seconds, HIGH severity alert fires. Normal users never do that — only attackers using tools like nmap. For SYN flood — if one IP sends 100 SYN packets in 10 seconds without completing the TCP handshake, that is a DDoS attack, we alert. For ARP spoofing — if one MAC address claims 3 or more different IPs, that indicates a Man in the Middle attack.

The backend uses Python, Flask with 9 API endpoints, and MongoDB. The frontend is React with Recharts for live graphs updating every 2 seconds. I also added an AI assistant using Ollama running locally — it uses RAG, fetching live MongoDB data before every response, so it answers specifically about your actual network, not generic responses.

I also built a pcap upload feature. A pcap file is a recorded network capture like Wireshark creates. Users upload it and my system analyzes it offline — shows total packets, protocol breakdown, top IPs. Useful for post-incident forensic investigation.

For testing I wrote 10 pytest unit tests using unittest.mock to patch the database function — tests never touch real MongoDB. They prove normal traffic does not false alarm, all three attacks are correctly detected, and whitelisted IPs like the router never trigger alerts. All 10 pass in under one second.

The main challenge was running packet capture and Flask API simultaneously — Scapy's sniff blocks forever. I solved it using Python threading — capture runs in a daemon thread, Flask on the main thread, both run simultaneously.

This project taught me network security, packet analysis, REST APIs, React real-time state management, MongoDB aggregation, unit testing with mocking, and RAG-based AI integration — similar to combining Snort, Wireshark, Splunk and Grafana but built from scratch."
